# Expose frontend

The Next.js PWA supports real multiplayer through the backend and an explicitly selected offline demo. Shared game rules/contracts live in `../shared`.

Run the combined app from the repository root with `npm run dev`. See [setup](../docs/SETUP.md), [architecture](../docs/ARCHITECTURE.md), [current status](../work-log/STATUS.md), and the [preserved mock frontend notes](../docs/MOCK_FRONTEND_HISTORY.md).

Design references remain in `color palette/`. Keep backend credentials out of this workspace.
